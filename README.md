## Analysis Overview

- **Tonality**: A-dur (3♯), with extensive modulations
- **Form**: Uvod – A – B – Insert – A' – B' – A'' – B'' – Tranzicija – A''' – **Repriza (E-DUR!!)** – Koda
- **Total measures**: ~900

### Key Harmonic Features

1. **Chromatic modulation A→As** (t.~338): half-step down, Mephisto's dance draws Faust's love
2. **Tritone modulations As↔E** (*diabolus in musica*): As–E = diminished fifth, Mephisto's symbol
3. **Dominant Reprise**: Entire reprise (t.675–806) is in **E-DUR (4♯)** = V of A, not A-dur
4. **Grand V→I cadence** at t.806–807: E→A, the "homecoming" resolution
5. **B♭ (♭VII/np) leitmotif**: appears as chromatic colour throughout A, E-dur reprise, and Coda

### Modulation Plan

```
A → As ↔ E → As → Des → B → E → A
     ↑triton↑        ↑IV↑  ↑V→I↑
```

## Methodology

Analysis follows Despić's functional notation:
- **T** = tonic (I), **S** = subdominant (IV), **D** = dominant (V), **D7** = V7
- **Sp** = subdominant parallel (VI), **np** = Neapolitan sixth (♭II6)
- **♭VII** = flat seventh degree, **D/D** = secondary dominant (V/V)
